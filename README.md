# Кейс 2.4 — Надійний телеметричний канал (хакатон)

Прототип протоколу телеметрії для розподілених сенсорних вузлів.
Стек: C (ESP32-вузли + шлюз на ноутбуці), MQTT як перший робочий
транспорт (з можливим переходом на власний UDP-протокол після
узгодження з ментором).

## Стан на зараз

- **Готово і перевірено (компіляція + тести):** `protocol/` (Блок A) —
  структура пакета, CRC32, pack/unpack, 19 unit-тестів, перевірено
  AddressSanitizer/UBSan.
- **Готово і РЕАЛЬНО скомпільовано + злінковано** (Артем, на своїй
  машині, зі справжніми `libmosquitto`/`libcjson` — найкраща перевірка
  з усіх, краща за все, що можливо в моєму середовищі): `gateway/gateway.c`
  (Блок C) — виправлена версія, прибрано заглушки
  `protocol_unpack`/`protocol_pack_ack`, які блокували всі реальні
  пакети. Лишилось: запустити і побачити живий трафік у dashboard.
- **Готово, перевірено компіляцією проти реального `protocol.c`
  (libmosquitto перевірено лише за сигнатурами, не лінковано — в
  моєму середовищі немає мережі для встановлення бібліотек;
  фінальна перевірка з реальною бібліотекою — на машині виконавця):**
  `sim_node/sim_node.c` (Блок D, Юрій, Рівень 1, реальний MQTT).
- **Готово, НЕ перевірено компіляцією (немає ESP32-тулчейну в цьому
  середовищі):** `node_accelerometer/`, `node_sht41/` (спільне ядро `node_common/node_common.h`) (Блок B, Кирило, Рівні
  1-3) — перша реальна перевірка на живій платі.

## Структура

```
protocol/          — protocol.h / protocol.c (спільний код, копіюється в node_accelerometer/node_sht41/gateway/sim_node)
tests/             — юніт-тести на C
node_common/       — спільне ядро вузла (node_common.h, packet_queue.h), sync.sh, raw_tests/
node_accelerometer/ — Arduino-скетч вузла з MPU9250
node_sht41/        — Arduino-скетч вузла з SHT41
gateway/           — C-програма шлюзу (MQTT-підписка, dashboard)
sim_node/          — симульований (3-й) вузол + тести на биті/loss/duplicate пакети
docs/              — специфікація, план по блоках, кейс
```

## Компіляція і тести (Блок A, готово)

```
cc -Wall -Wextra -Iprotocol tests/test_protocol.c protocol/protocol.c -o test_protocol
./test_protocol
```

Має вивести `Тестів: 19, провалено: 0`.
